================================================================================
                          SECURITY FEATURES
================================================================================

✅ LEAST PRIVILEGE ACCESS
   - Users access only their own data by default
   - Public resources require explicit visibility
   - Sharing controlled via pool membership

✅ DATA CLASSIFICATION
   - Public Reference Data: tournaments, teams, matches (read-only)
   - User Data: predictions, scores (access controlled)
   - System Data: audit logs, notifications (append-only/read-own)

✅ TIME-BASED ACCESS CONTROL
   - Predictions locked 10 minutes before match kickoff
   - Others' predictions hidden until after lock time
   - Enforced via RLS policy + trigger

✅ RELATIONSHIP-BASED ACCESS
   - Pool membership determines read access
   - Public/private visibility controls data sharing
   - Owner-only modification rights

✅ SYSTEM VS USER OPERATIONS
   - Users control: pools, predictions
   - System controls: scores, notifications, audit logs
   - Clear separation prevents data corruption

✅ MULTI-LAYER ENFORCEMENT
   - Layer 1: RLS Policies (primary enforcement)
   - Layer 2: Triggers (secondary enforcement + auditing)
   - Layer 3: Application logic (optional 3rd layer)
