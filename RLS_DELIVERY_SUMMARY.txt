HELPER FUNCTIONS (5 Total)
═════════════════════════════════════════════════════════════════════════════════

1️⃣  is_pool_member(user_id, pool_id) → BOOLEAN
    • Check if user is pool owner or participant
    • Used by multiple access control policies
    • SECURITY DEFINER with execute grants

2️⃣  is_match_locked(match_id) → BOOLEAN
    • Check if match is locked for predictions
    • Lock time = kickoff - 10 minutes
    • Used by prediction policies and triggers

3️⃣  can_see_match_results(match_id) → BOOLEAN
    • Check if match results are visible
    • Same logic as lock time (bonus function)
    • Used by future result visibility policies

4️⃣  check_prediction_lock() [TRIGGER FUNCTION]
    • Enforces prediction lock on UPDATE
    • Raises exception if match is locked
    • Safety net for database-level enforcement

5️⃣  log_prediction_audit() [TRIGGER FUNCTION]
    • Logs prediction changes to audit table
    • Records old/new values
    • Only logs if values actually changed
