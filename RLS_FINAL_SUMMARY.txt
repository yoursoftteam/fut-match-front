SECURITY POLICIES SUMMARY
═══════════════════════════════════════════════════════════════════════════════

bet_tournaments (4 policies)
  ├─ SELECT: Public read-only for authenticated users
  └─ INSERT/UPDATE/DELETE: Disabled for users (admin only)

bet_teams (4 policies)
  ├─ SELECT: Public read-only for authenticated users
  └─ INSERT/UPDATE/DELETE: Disabled for users (admin only)

bet_matches (4 policies)
  ├─ SELECT: Public read-only for authenticated users
  └─ INSERT/UPDATE/DELETE: Disabled for users (admin only)

bet_pools (6 policies) ✨ KEY TABLE
  ├─ SELECT: Public pools visible to all
  ├─ SELECT: Private pools visible to owner/members
  ├─ INSERT: Owner-only creation
  ├─ UPDATE: Owner-only modification
  └─ DELETE: Owner-only deletion

bet_match_predictions (5 policies) ✨ KEY TABLE
  ├─ SELECT: Own predictions always + others after lock time
  ├─ INSERT: User-only if not locked (kickoff - 10 min)
  ├─ UPDATE: User-only if not locked
  ├─ DELETE: User-only if not locked
  └─ TRIGGER: Enforce lock time + audit logging

bet_scores_aggregate (6 policies)
  ├─ SELECT: Own + pool visibility based access
  └─ INSERT/UPDATE/DELETE: System-only (users blocked)

bet_audit_log (4 policies)
  ├─ SELECT: Own records only
  └─ INSERT/UPDATE/DELETE: System-only (triggers)

bet_notification_queue (4 policies)
  ├─ SELECT: Own notifications only
  └─ INSERT/UPDATE/DELETE: System-only (backend)

bet_pool_config_versions (6 policies)
  ├─ SELECT: Owner/member access
  └─ INSERT/UPDATE/DELETE: Owner-only


HELPER FUNCTIONS (5 TOTAL)
═══════════════════════════════════════════════════════════════════════════════

1. is_pool_member(user_id UUID, pool_id UUID) → BOOLEAN
   Purpose: Check if user is pool member
   Used by: Multiple access control policies
   Performance: Optimized with indexed lookups

2. is_match_locked(match_id UUID) → BOOLEAN
   Purpose: Check if match is locked for predictions
   Logic: NOW() > (kickoff - 10 minutes)
   Used by: Prediction policies and triggers

3. can_see_match_results(match_id UUID) → BOOLEAN
   Purpose: Check if match results are visible
   Logic: NOW() > (kickoff - 10 minutes)
   Used by: Future result visibility policies

4. check_prediction_lock() [TRIGGER]
   Purpose: Enforce lock time on UPDATE
   Action: Raise exception if locked

5. log_prediction_audit() [TRIGGER]
   Purpose: Log prediction changes to audit table
   Action: INSERT audit log entry with old/new values

✓ Delete predictions (when not locked)

✗ Create or modify tournaments (admin only)
✗ Create or modify teams (admin only)
✗ Create or modify matches (admin only)
✗ Modify another user's prediction
✗ Predict after match lock time (kickoff - 10 min)
✗ Insert or update scores (backend only)
✗ Read others' notifications
✗ Modify audit log
✗ Bypass RLS policies (impossible for users)

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

See RLS_DEPLOYMENT_GUIDE.md for complete troubleshooting guide.

Common issues:
  "Permission denied for schema public"
    → RLS policy is blocking the operation
    → Check if you have permission for this action

  "Cannot update prediction after match lock time"
    → Trigger rejected UPDATE due to lock time
    → Match is within 10 min of kickoff

  "Violates row-level security policy"
    → INSERT/UPDATE values violate the policy
    → Check the WITH CHECK condition
